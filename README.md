# Lab4Web — Praktikum 4: CSS Layout

## Struktur Folder

* `lab4_box.html` — Box Element, CSS Float Property, dan Clearfix.
* `home.html` — Layout sederhana.
* `style.css` — CSS layout sesuai langkah modul.
* `about.html` — Tugas halaman About.
* `kontak.html` — Tugas halaman Contact.

## Langkah Praktikum

1. Membuat dokumen `lab4_box.html` dengan judul Box Element.
2. Membuat Box Element menggunakan `div` dengan kelas `div1`, `div2`, dan `div3`.
3. Menerapkan `float:left` dan padding pada elemen `div`.
4. Menambahkan `div4` serta properti `clear: left` dan `float: none`.
5. Membuat folder `lab4_layout`, lalu membuat `home.html` dan `style.css`.
6. Membuat kerangka layout menggunakan elemen semantik `header`, `nav`, `section`, `aside`, dan `footer`.
7. Menambahkan CSS untuk header dan navigasi.
8. Menambahkan Hero Panel.
9. Mengatur main content dan sidebar menggunakan float.
10. Menambahkan Sidebar Widget.
11. Mengatur footer.
12. Menambahkan tiga box konten dan dua artikel.
13. Membuat halaman About berisi deskripsi dan portfolio.
14. Membuat halaman Contact berisi form nama, email, dan message.
